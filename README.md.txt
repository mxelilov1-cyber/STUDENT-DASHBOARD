# Student Performance Dashboard 🎓

Bu layihə **Streamlit** və **SQL Server** istifadə edərək tələbə nəticələrinin idarə edilməsi və izlənilməsi üçün hazırlanmış kiçik web tətbiqidir.

## 🛠️ Layihənin Strukturu
Layihə Clean Code prinsiplərinə uyğun olaraq aşağıdakı modullara bölünmüşdür:
* **`app.py`** - Streamlit istifadəçi interfeysi (UI)[span_0](start_span)[span_0](end_span)
* **`database.py`** - SQL Server verilənlər bazası əlaqələri[span_1](start_span)[span_1](end_span)
* **`services.py`** - Biznes məntiqi (qiymətləndirmə və statistika hesablamaları)[span_2](start_span)[span_2](end_span)
* **`config.py`** - Konfiqurasiya və bağlantı parametrləri[span_3](start_span)[span_3](end_span)
* **`requirements.txt`** - Lazımi kitabxanaların siyahısı[span_4](start_span)[span_4](end_span)
